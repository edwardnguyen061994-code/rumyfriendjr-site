Privacy on this website

Last updated 15 September 2026

This page is about www.rumyfriendjr.com, this website only. The RumyFriend Jr app collects information in order to work, and it has its own Children’s Privacy Notice covering that. This page does not describe the app.

What this website collects

Nothing. There is no sign-in, no form, no newsletter box and no comment field anywhere on this site. We set no cookies. We run no analytics, no advertising and no third-party scripts — every image, font and video on the site is served from this domain, so loading a page tells nobody else that you visited.

The one piece of JavaScript on the site starts and pauses the short game preview videos as you scroll. It stores nothing and sends nothing.

Server logs

This site is hosted on GitHub Pages. Like any web host, GitHub records ordinary request information such as IP address, in order to serve the site and protect it from abuse. We do not receive, access or store those logs, and we do not use them to build a profile of anyone. GitHub’s handling of that data is described in their own privacy statement.

Links to the games

Each game on this site is hosted on its own address and opens in a new page. Once you leave this site you are on that game’s page, and what it collects is described by its own terms. We send no information about you along with the link: the site sets referrer: no-referrer, so the game is not told which page you came from.

Children

This site is aimed at parents and at children aged 4–12, and it is built so that visiting it creates no record we hold. If you believe we have somehow collected information from a child through this website, email contact@rumyfriendjr.com and we will delete it.
