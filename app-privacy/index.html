RumyFriend Jr app privacy

This notice describes the games-only iOS release of RumyFriend Jr, version 1.1.0. RumyFriend LLC operates the app. For questions about a child's information, contact contact@rumyfriendjr.com.

The app opens to games without creating an account. This release has no Friends list, private messaging or personal-photo profile. It does not use the adult RumyFriend app's Meet or location-search features.

Guest play and game information

The app stores a randomly generated guest identifier on the device and uses it when opening games. This is separate from a RumyFriend account. The app supplies the generic player label “Player” and no profile photograph. Games can have their own player-name and game-input controls. Use a game nickname, rather than a child's full name, school, address, email address or phone number.

Game services receive identifiers, player labels, room and participant information, game inputs, game state and scores needed to operate the games. Other players in a game may see player labels, game contributions and scores. Playing alongside someone does not create an app friendship or enable an app private conversation.

Favorites and some game progress are stored locally. Updating from an earlier test build clears old web sign-in and game browser data before guest play begins. Clearing local data does not remove records already stored by a game service.

Providers and use

Games are hosted web applications. Hosting, game-server and content-delivery providers receive requests and ordinary connection information, such as an IP address, to deliver and protect the service. Game information is used to run game rooms and gameplay.

We also use gameplay records to understand which games are played and how often players return, so we can improve the service. These records can be associated with the app's guest identifier.

Service providers also retain technical diagnostics, such as request outcomes and processing times, to operate and troubleshoot the games.

We do not sell children's information or use it for marketing or advertising. We do not use the app's guest identity or gameplay records for tracking across other companies' services for advertising.

Information and features removed from this release

The games-only app does not ask for an account email address, password, date of birth or personal-photo profile. Account sign-in, personal-photo processing and social notifications are not available in this release. The app does not request device location, camera, microphone or photo-library permission.

Parent requests

Contact contact@rumyfriendjr.com to ask about information held by a game service or to request access, correction or deletion. Include the game name and the relevant player label or room code if available; do not email a password. A local reset cannot delete a server record or a record already received by another player. Contact us about the scope and status of a request.

Changes and contact

This notice applies to the games-only app release described above. If its collection or features change, this notice will be updated to describe them. The older service policy also describes account-based test features that are not available in this games-only release.
